# AI-дайджест для новичков

Одностраничный промо-сайт на Flask: светлый интерфейс с неоновыми акцентами,
девять материалов-карточек и страницы-заглушки. Без базы данных и
UI-библиотек.

## Как запустить

```bash
cd /Users/a123/Documents/ZeroCoding/Website_AI_for_beginners
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте <http://127.0.0.1:5000>.

Если порт 5000 занят, проверьте процесс и остановите его либо временно
запустите приложение на другом порту:

```bash
lsof -nP -iTCP:5000 -sTCP:LISTEN
```

Для запуска на другом порту без правки кода:

```bash
flask --app app run --port 5001
```

## Проверка

## Маршруты

| Метод | URL | Назначение |
| --- | --- | --- |
| GET | `/` | Главная страница с девятью карточками |
| GET | `/material/<int:id>` | Страница материала `1–9` |
| GET | `/material/<неизвестный id>` | Страница 404 |

## Контент

Все материалы лежат в списке `cards` в `app.py`. У карточки четыре поля:

```python
{
    "id": 1,
    "title": "Что такое нейросеть",
    "subtitle": "Объясняем на пальцах, без формул и сложных терминов.",
    "image_url": "https://images.unsplash.com/photo-...?w=800&q=80",
}
```

Чтобы добавить материал, скопируйте словарь, задайте новый `id` и обновите
заголовок раздела на главной. Сейчас карточек девять — это соответствует
требованию 8–10.

## Оформление и поведение

- Палитра задана переменными в начале `static/css/style.css`:
  `--bg: #f4f6fa`, `--text: #121722`, `--accent: #0e7490`,
  `--accent-2: #7c3aed`. Светлая тема зафиксирована через
  `color-scheme: light`.
- Сетка карточек: 4 колонки от 1320 px, 3 от 1024 px, 2 от 640 px, 1 на
  телефоне.
- Hover карточки: подъём на 8 px, затемнение и масштабирование обложки,
  полупрозрачный неоновый слой и смена цвета кнопки. Всё на CSS `transition`.
- JS — только улучшения: появление блоков через `IntersectionObserver`,
  подсветка активного пункта меню, тень шапки и свечение за курсором.
  Без JS карточки остаются видимыми.
- Учтён `prefers-reduced-motion`: анимации отключаются.
- Кнопки и ссылки имеют `:focus-visible`, есть skip-link и `aria`-подписи.
- Логотип AiMaximum — прозрачный PNG `static/img/logo.png`, обрезанный по
  контенту из `ForMaxOnly/AiMaximum.jpeg`. Он используется в шапке и подвале
  через общий шаблон `templates/base.html`; favicon — `static/img/favicon.png`.
  Для светлого фона подпись «AIMAXIMUM» перекрашена в тёмный цвет, а белое
  свечение исходника мягко растворяется на светлой шапке.
- В центре hero-круга вместо надписи «AI / start here» проигрывается
  зацикленное видео `static/media/ai-chip.mp4` (`muted`, `playsinline`, `loop`).
  Постер и обязательный фолбэк — `static/img/ai-chip.jpg`. При
  `prefers-reduced-motion`, отсутствии поддержки MP4 или ошибке
  воспроизведения показывается постер. Видео перезапускается каждые 30 секунд
  и ставится на паузу, когда вкладка скрыта.
- Видео инвертируется и смешивается в режиме `screen`, поэтому белый фон
  исходного ролика не виден на тёмном ядре; круглая маска убирает водяной знак
  и оставляет чип в центре круга.

## Ограничения

- Обложки загружаются с Unsplash, шрифты — с Google Fonts. Без интернета
  останется светлая вёрстка, но изображения и фирменный шрифт не загрузятся.
- `python app.py` запускает встроенный сервер Flask с `debug=True`. Это
  учебный режим; для публикации нужен WSGI-сервер и `debug=False`.
- Базы данных, авторизации и формы подписки нет — сайт статичный по контенту.
- Логотип и видео AiMaximum — локальные файлы, внешние ассеты для них не
  используются.
